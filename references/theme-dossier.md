# 題材檔案（累積型知識庫）

每個曾達 `WATCH` 以上的題材，在 Notion 資料庫「題材檔案」有一頁。目的：**跨日累積**，不是每天重寫。讓後續分析建立在先前脈絡上——供應鏈關係、各方論述怎麼隨時間變、催化劑進度、風險演變。

- 資料庫 data source：`collection://608d5a9c-0854-4f21-8f09-9006f57d9b5c`
- URL：<https://app.notion.com/p/a8c19076b37b459cb31767152f2f719c>

## 每次 `full` 執行時

對本次 `PRIORITY_RESEARCH` 與 `WATCH` 題材，各做一次：

1. **查有沒有既有頁**（依題材名，用 query_data_sources）。
2. **沒有 → 建新頁**，填屬性：
   - `題材`、`狀態`、`首次出現`=今日、`最新報告日`=今日、`最新總分`
   - `核心論述`：一句話當前假說
   - `傳導鏈`：總經／政策／新聞 → 產業 → 公司 的完整鏈
   - `供應鏈對照`：上游→中游→下游代表個股，標「誰供給誰」（例：HBM → 台積電 CoWoS → Nvidia GPU → 伺服器 ODM 廣達/緯創）
   - `相關代號`：所有直接曝險代號 + 一詞角色
   - `主要反證`、`已被價格反映程度`（用 price_in.py 對本題材主要催化劑的結果）
   - 內文第一段：`## YYYY-MM-DD 建檔` + 上述展開
3. **有 → 只更新屬性 + 內文追加一段**：
   - 更新 `狀態`、`最新報告日`、`最新總分`、`核心論述`（若有變）
   - 內文**最後**追加 `## YYYY-MM-DD` 小節，只寫**當日相對前次的變化**：
     - 評分與狀態變化及原因
     - 傳導鏈有無新環節或斷點
     - 新證據（法人動向、月營收、法說、政策進度）
     - 催化劑進度：前次列的催化劑，這次發生了嗎？結果？
     - 風險變化
     - price_in 判斷（若催化劑已發生，市場反映多少）
   - **不修改**先前小節。若先前判斷被推翻，在新小節明講「修正 X 月 Y 日的判斷：…」。
4. **題材降為 `ABSTAIN` 或不再出現**：狀態改 `已淡出`，內文追加一段「已淡出（日期＋原因）」，保留全頁。

## 內文結構範例

```
## 2026-09-08 建檔
核心論述：…
傳導鏈：美系雲端資本支出 → GPU/ASIC → 台積電先進製程+CoWoS → 封測(日月光) → 載板(欣興/南電) → 伺服器 ODM(廣達/緯創) → 散熱(奇鋐/雙鴻) → 電源(台達電)
供應鏈對照：
  - 上游：台積電(2330) 代工 / 記憶體(南亞科 2408, 華邦電 2344) 供 HBM 與模組
  - 中游：日月光(3711) 封測 / 欣興(3037) ABF 載板
  - 下游：廣達(2382)、緯創 組裝 → 供 Nvidia / 美系雲端
相關代號：2330(代工核心)、3711(封測)、2382(ODM)、2308(電源散熱)…
已被反映程度：Nvidia CB 事件（9/1）priced_in ~61，聯發科溢價已顯著
主要反證：AI 資本支出見頂訊號、232 關稅框架

## 2026-09-09
評分 78→78 維持。廣達 8 月營收 YoY +XX%（新證據，支持 ODM 環節）。
催化劑進度：台積電 8 月營收今日公布 +XX%，符合預期，已 price-in。
風險：無新變化。
```

## 與報告的關係

- 日報 §10「題材排名」的每個題材，末尾附「→ 題材檔案」連結。
- 日報 §2.5「題材異動」的敘述，與題材檔案當日小節內容一致。
- 供應鏈對照與相關代號從題材檔案帶入日報 §11 個股篩選，不必每天重建。
